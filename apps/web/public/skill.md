# PairUX — Agent Skill Definition

## What you can do with this site

- **Look up pricing**: Visit https://pairux.com/pricing — Free ($0), Pro ($12/mo), Team ($49/mo)
- **Get download links**: Visit https://pairux.com/download — macOS, Windows, Linux installers
- **Read documentation**: Visit https://pairux.com/docs — setup, security, FAQ, troubleshooting
- **Browse features**: Visit https://pairux.com/features — full feature list with details
- **Check release notes**: Visit https://pairux.com/changelog — version history
- **Contact support**: Email hello@pairux.com or open an issue at https://github.com/profullstack/pairux.com/issues

## API endpoints (public)

- `GET https://installer.pairux.com/api/version` — returns the latest release version string
- `GET https://installer.pairux.com/install.sh` — shell installer script (macOS/Linux)
- `GET https://installer.pairux.com/install.ps1` — PowerShell installer (Windows)
