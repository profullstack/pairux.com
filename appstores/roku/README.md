# Roku Channel Store (pairux.com)

Not built yet.

**What it takes:** a SceneGraph/BrightScript channel, a developer account at
developer.roku.com, and — the part that catches people — a **physical Roku in
developer mode**: the store only accepts a `.pkg` signed on a device, and a
plain zip is refused with "Package file has an invalid header".

**Before the first upload**

- Roku reviews against its own channel guidelines, and asks for test credentials
  that work from a cold start.
- The listing needs its own poster art sizes, unrelated to the other stores'.
